Why continuous batching won

Both schedulers below get the identical stream of requests, the identical number of slots, and the identical work to do. The only difference is when a finished request gives its slot back. Watch the right-hand lane stay full while the left one drains.

Static batching

A slot is freed only when the whole batch finishes.

slot utilisation0%

Continuous batching

A slot is freed the moment its own request finishes.

slot utilisation0%

The waste is not the GPU being slow — it is a finished request holding a slot while a longer one in the same batch keeps going. That idle time is the straggler problem, and it gets worse the more your output lengths vary, which is exactly what real traffic does.
