What this is. A planning model, not a benchmark. Memory figures are exact arithmetic on the shapes you chose; activation memory follows Megatron-LM's accounting and is an estimate that varies with implementation. Communication assumes the link runs at its rated bandwidth with no overlap — a real run overlaps most of it with the backward pass, so treat the ring column as an upper bound.
