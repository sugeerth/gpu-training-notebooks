The same copy, twice

Both kernels copy an array. They differ only in which element each thread handles, and on a real GPU that difference is worth about 8x. The warp panel shows why: one load instruction, 32 lanes, and the 32-byte sectors the memory system has to fetch.

Shared memory is 32 banks, and only one address each per cycle

  
Address a lives in bank (a/4) % 32. If the warp's 32 lanes
  hit 32 different banks it is one cycle; if they all hit one bank it is 32, serialized. Both
  kernels below compute the same reduction tree. Only the index arithmetic differs.

What the panels compute. The sector count is the number of distinct
32-byte regions the warp's 32 addresses fall into — the same rule the memory system
applies. The bank figure is the largest number of distinct addresses any single bank is
asked for, which is the serialization factor. Both are computed here from the addresses the
code on the left actually produces, not from a lookup table.
